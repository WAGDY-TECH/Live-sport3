# ⚽ LiveSportsApp — تطبيق بث مباشر للمباريات

تطبيق أندرويد احترافي لمشاهدة القنوات الرياضية مباشرة مدمج مع ملف قنوات **M3U** جاهز يحتوي على أكثر من **530 قناة رياضية** من مشروع [iptv-org](https://github.com/iptv-org/iptv) المفتوح المصدر.

## ✨ المميزات

- **بث مباشر** عبر تقنية ExoPlayer (دعم HLS / m3u8)
- **534 قناة رياضية** مدمجة مسبقًا لا تحتاج أي إعداد
- **بحث فوري** في أسماء القنوات
- **فلترة حسب الدولة** عبر شارات قابلة للاختيار
- **قائمة مفضلة** (اضغط مطولًا على القناة لإضافتها)
- واجهة عربية داكنة احترافية سريعة
- دعم **تحميل قائمة M3U من رابط خارجي** من القائمة
- تشغيل بتملء الشاشة أفقيًا مع شريط تحكم كامل

## 📲 تثبيت الـ APK

1. حمّل ملف `app-release.apk` من هذا المستودع
2. انقله لهاتفك ثم ثبّته (سمح بـ "مصادر غير معروفة" عند السؤال)
3. افتح التطبيق واختر قناة وشاهد البث مباشرة

> ملاحظة: بعض القنوات قد تكون غير متاحة في وقت معين حسب المنطقة أو حالة الخادم — جرّب قناة أخرى.

## 🏗️ البناء من المصدر

```bash
./gradlew assembleRelease
```

الناتج: `app/build/outputs/apk/release/app-release.apk`

## 📁 هيكل المشروع

```
app/src/main/
├── java/com/wagdytech/livesports/
│   ├── MainActivity.kt      # قائمة القنوات + البحث + الفلاتر
│   ├── PlayerActivity.kt    # مشغل البث ExoPlayer
│   ├── ChannelAdapter.kt    # واجهة عرض القنوات
│   ├── M3UParser.kt         # محلل ملفات M3U
│   └── Stores.kt            # تخزين المفضلة والإعدادات
├── assets/channels.m3u      # قائمة القنوات الرياضية المدمجة
└── res/                     # الواجهات والثيم الداكن
```

## 🔄 تحديث القنوات

استبدل الملف `app/src/main/assets/channels.m3u` بأي قائمة M3U جديدة من:
`https://iptv-org.github.io/iptv/categories/sports.m3u`

أو حمّل أي قائمة من داخل التطبيق: القائمة ⋮ ← "تحميل قائمة M3U من رابط".

## ⚖️ إخلاء مسؤولية

القنوات المدمجة مصدرها مشروع iptv-org الذي يجمع روابط بث متاحة علنًا على الإنترنت. هذا المشروع لأغراض تعليمية، والمستخدم مسؤول عن التوافق مع قوانين بلده وحقوق البث المحلية.
